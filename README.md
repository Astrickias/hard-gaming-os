# Hard Gaming OS 2.3.0 Beta

Quellpaket für Hard Gaming OS (seit 2.3.0 eine Edition für Gaming und Alltag). Das Live-Profil enthält Hard-Gaming-Bootmenüs, Plymouth-Theme, Plasma-Hintergrund, Anmeldehintergrund und den Calamares-Installer mit Hard-Gaming-Branding. Die Calamares-Hooks übernehmen die Systemkennung und das Branding ins Zielsystem.

Siehe [Build und VM-Test](docs/UPSTREAM.md), [Test 2.3.0](docs/TEST-2.3.0.md) und [Änderungen](dist/Aenderungsliste-2.3.0-beta.md). Hard Gaming Family bleibt ein Architekturentwurf.
