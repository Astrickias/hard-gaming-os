# Hard Gaming OS 2.1.5 Beta

Quellpaket für die Gaming und Allround Edition. Beide Live-Profile enthalten Hard-Gaming-Bootmenüs, Plymouth-Theme, Plasma-Hintergrund, Anmeldehintergrund und den Calamares-Installer mit Hard-Gaming-Branding. Die Calamares-Hooks übernehmen die Systemkennung und das Branding ins Zielsystem.

Siehe [Build und VM-Test](docs/UPSTREAM.md), [Test 2.1.5](docs/TEST-2.1.5.md) und [Änderungen](dist/Aenderungsliste-2.1.5-beta.md). Hard Gaming Family bleibt ein Architekturentwurf.
